# K1 AUTO 랜딩페이지

K1 Auto(케이원오토) 홈페이지에 공개된 주요 서비스 문구와 연락처를 참고해 만든 독립형 HTML/CSS/JavaScript 랜딩페이지입니다.

## 실행 방법

1. `index.html`, `style.css`, `script.js`를 같은 폴더에 둡니다.
2. `index.html`을 Chrome, Safari 등 브라우저에서 엽니다.
3. 인터넷 연결 시 Google Fonts와 외부 차량 이미지가 로드됩니다.
